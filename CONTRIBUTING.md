# Contributing

Thanks for taking a look at this project. It's a small hobby game, so the process is
intentionally light.

## Getting set up

See the [README](README.md#setup) for Firebase setup — you'll need your own Firebase
project(s) since none are committed to the repo.

## Making a change

1. Fork the repo and create a branch off `main`.
2. Keep changes focused — one feature/fix per PR is easier to review than a bundle.
3. Match the existing code style. CI runs `dart format --set-exit-if-changed` and
   `flutter analyze`; make sure both pass before opening a PR (`dart format .` will
   fix formatting for you).
4. Open a PR describing what changed and why.

## Reporting bugs / suggesting features

Open a GitHub issue using the relevant template. Screenshots or steps to reproduce are
always appreciated for bugs.
